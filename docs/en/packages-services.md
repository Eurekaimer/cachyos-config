for install input, the rest for the captured state). "Refresh" values are
generated by `./scripts/capture.sh`; the capture timestamp is recorded in
`state/system-info.txt` as `captured_at`.

`packages/inventory/software-census.txt` counts **software**, not packages:
277 explicitly installed packages merge into 134 software entries (38 apps,
71 tools/runtimes, 25 system/desktop groups), plus 6 items from other package
managers (cargo 4, go 1, uv 1), for 140 in total. The merge table (seven
fcitx5 packages are one input method, six texlive packages are one TeX Live)
lives at the top of `scripts/pkgcensus.sh`; any explicitly installed package
missing from it is listed at the end of the report, so seeing that section
means the table needs an entry. Regenerate with:

```bash
./scripts/pkgcensus.sh > packages/inventory/software-census.txt
```

`packages/profiles/*.txt` is the only install input for packages;
`packages/required-extra.txt` adds the dependencies the recovery tooling itself
needs. The `inventory/`, `services/` and `toolchains/` trees are capture output
and describe the machine the snapshot came from. Compare two profiles with
`./scripts/profile.sh diff full minimal`, and select one with
`./scripts/profile.sh use minimal` or `./scripts/install-packages.sh --profile minimal`.

Refresh all generated lists with `./scripts/capture.sh`. Restore packages alone with `./scripts/install-packages.sh`, and restore enablement state with `./scripts/restore-services.sh`. Missing service units are skipped rather than fabricated.
